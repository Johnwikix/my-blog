用 C# 写 Compute Shader：ComputeSharp 实战笔记

把 Shadertoy 的体积云搬进 WinUI 3 窗口——ComputeSharp 的 HLSL 源生成器、SwapChainPanel 的 DPI 坑，以及 HDR 检测的正确姿势。

图形学ComputeSharpWinUI 3HLSL

ComputeSharpDemo 这个项目起源于一个朴素的想法：在 C# 里写 shader，像写普通方法一样。ComputeSharp 通过源生成器把这个想法变成了现实——你在 C# 里写一个 IComputeShader<T> 结构体，编译期它就被翻译成 HLSL，跑在 D3D12 compute pipeline 上。

源生成器的魔法

核心体验是这样的：

[ThreadGroupSize(DefaultThreadGroupSizes.X)]
public readonly partial struct ProteanClouds(float time, float2 res, ReadWriteTexture2D<float4> output)
    : IComputeShader
{
    public void Execute()
    {
        float2 uv = (float2)ThreadIds.XY / res;
        // raymarch、fbm、调色……全部 C# 语法
        output[ThreadIds.XY] = new float4(color, 1f);
    }
}

没有 .hlsl 文件、没有运行时字符串拼接、没有手动管 ConstantBuffer 布局。捕获的局部变量自动变成 shader 常量，类型系统直接映射 HLSL 类型。写错了编译期就报错，而不是黑屏之后对着像素调试器发呆。

移植 Shadertoy：三次坐标变换的学费

项目里内置的第一个 shader 是 nimitz 的 Protean Clouds（体积云 raymarching，CC BY-NC-SA 3.0）。移植本身不难，难的是坐标系换算的每一处细节：

  • Shadertoy 的 fragCoord 原点在左下角，D3D 的像素坐标原点在左上角——Y 要翻转。
  • Shadertoy 的 iMouse 语义要自己设计映射，compute shader 没有内建的输入状态。
  • 通道纹理（iChannel0）需要自己生成或者替换成程序化噪声。

第二个大坑是 Apple Music 风格背景的移植。原版（Lyricify-Backgrounds）是像素 shader 里的 UV 弯曲（pinch mesh），但 ComputeSharp 只有 compute shader——没有插值器帮你做 UV 逆变换。解法是对每个像素做牛顿迭代求逆变换：把正向 pinch 函数当成方程，迭代解出「这个像素来自哪个 UV」。另一个伴随的 77-tap 可分离高斯模糊也顺手实现了。

SwapChainPanel 的 DPI 坑

WinUI 3 的 SwapChainPanel 有个知名问题（winui#8219）：DPI 变化时它给你的尺寸是 DIP 而不是物理像素。解法是维护双份尺寸方案——物理像素尺寸用于 swap chain 创建和 shader dispatch，DIP 尺寸用于布局。另外我用一个 500ms 节流的兜底定时器轮询 DPI 变化，因为依赖单一事件在某些显示器热插拔时序下会漏。

HDR：比想象中更碎

HDR 支持是典型的「80% 时间花在 20% 的边角」：

  • DisplayInformation (WinRT) 和 DXGI output 查询各说各话，需要两边交叉验证；
  • 窗口跨显示器拖动时要重新评估；
  • 用户在 Windows 设置里开关 HDR 时，HDR 状态变更事件不一定及时——最终也是事件 + 兜底轮询双保险。

输出侧还要处理 FP16 swap chain、色彩空间（ scRGB vs HDR10）和 SDR 白电平映射。这些经验后来直接喂给了 DXRDemo 的 HDR10 输出。

插件式 shader 目录

最后的架构是目录式的：每个 shader 一个入口类，注册进 catalog。新增一个 shader 大概动三个文件，不碰主窗口逻辑。目前目录里有：

  1. Protean Clouds — 体积云 raymarching
  2. Ray Trace — 蒙特卡洛路径追踪（可调弹射次数、时域累积或 RELAX 降噪）
  3. Apple Music Inspired — 牛顿迭代逆变换版

结语

ComputeSharp 的意义在于降低了「试一试」的门槛。以前一个 shader 想法从萌生到上屏要配一整套 C++ 工程；现在它就是 C# 解决方案里的一个 struct。对教学、原型、还有给播放器做 shader 背景这种需求，体验是碾压级的。

项目 MIT 开源，附带 hdr-pitfalls.md 和 ADD_NEW_SHADER.md 两份踩坑文档——都是学费换来的。
