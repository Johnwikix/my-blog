关于

我是 Johnwikix，也就是 Sennpei Studio—— 一个在 Windows 桌面上折腾 native 代码的开发者。简介栏写着「Can't tell you」， 因为我更习惯让代码自己说话。

我的兴趣很集中：高保真音频和 GPU 驱动的画面。 白天和 FFmpeg 的采样率搏斗，晚上和弹射光线的方差搏斗， 偶尔还要跟 WinUI 3 的 DPI 改版事件讲讲道理。

我在造什么

  • 原音 HQ 播放器——旗舰项目，一切从「无损」两个字展开
  • DXRDemo——在 WinUI 3 里从零手搓 DXR 路径追踪
  • ComputeSharpDemo——用 C# 写 D3D12 compute shader 的试验场
  • 以及一堆让开发更顺手的小工具

这个站

信号实验室（SIGNAL LAB）——一个从零手写的静态博客：Astro 构建，Markdown 写作， 首页背景是一片实时渲染的 GLSL 星云，页脚跑着一条伪 FFT 频谱。 告别 Hexo 的原因和重建过程，写在这篇日志里。
